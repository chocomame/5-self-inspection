# WEBサイトSEOチェッカー

指定したドメインのWEBサイトに対して、各ページのタイトル、メタディスクリプション、見出し構造、画像のalt属性をチェックするツールです。

## 機能

- 指定したドメイン内の全ページを自動クロール
- タイトルが50文字を超えているページを検出
- ディスクリプションが140文字を超えているページを検出
- 見出しタグ（h1-h6）の順序チェック
  - 出しレベルが適切に階層化されているか確認（例：h1からh3への飛びがないか）
- 英語のみの見出しタグを検出
  - 病名や英語でしか表現できない用語は除外
- 画像のalt属性チェック
  - alt属性が設定されていない画像を検出
- アンカーリンクのページは除外
- ドメイン外のリンクは除外
- 結果をCSVでダウンロード可能

## セットアップ

### ローカル実行（非エンジニア向け）

ダブルクリックで起動できるランチャーと説明書を別途用意しています。
このリポジトリには含めていないため、必要な場合は管理者に依頼してください。

- 初回起動時に `.venv` を自動作成し、必要なライブラリをインストールします
- **対応Python: 3.10〜3.13**（3.14以降は未対応）
- Windowsではフォルダのパスが100文字を超えると停止します
  （streamlit の同梱ファイルが深い階層にあり、MAX_PATH(260) を超えて
  `WinError 206` でインストールに失敗するため）

### 手動で動かす場合

1. 必要なパッケージのインストール:
```bash
pip install -r requirements.txt
```

2. アプリケーションの起動:
```bash
streamlit run app.py --server.showEmailPrompt=false --browser.gatherUsageStats=false
```

## ローカル実行を用意している理由

エックスサーバーなどのレンタルサーバーは、海外クラウドが持つIPアドレスを
まとめて遮断しています。Streamlit Community Cloud は米国の共有IPから通信するため、
遮断されたサイトはブラウザ版ではチェックできません（TCP接続の段階で弾かれるので、
User-Agentの偽装やリトライ回数の変更では回避できません）。

お手元のパソコンから実行すれば日本国内からの通信になるため、問題なくチェックできます。

## 使用方法

1. ブラウザで表示されたStreamlitアプリにアクセス
2. チェックしたいWEBサイトのURLを入力
3. 「チェック開始」ボタンをクリック
4. タブ別に各チェック結果を確認
   - タイトル・ディスクリプション
   - 見出し構造
   - 英語のみの見出し
   - 画像alt属性
5. 必要に応じて結果をCSVでダウンロード
